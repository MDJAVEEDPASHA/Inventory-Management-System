# Inventory and Order Management System

A lightweight, console-based inventory and order management system built with Python and SQLite. This project helps track product stock levels, update inventory, and process customer orders securely using a local relational database.

## Features
- **Product Management:** View existing products and add new items to the inventory.
- **Stock Tracking:** Automatically update stock quantities as changes occur.
- **Order Processing:** Place customer orders and handle transactions with foreign key constraints.
- **Database Persistence:** Uses SQLite to ensure data remains saved locally between sessions.

## Tech Stack
- **Language:** Python 3
- **Database:** SQLite3
